# Advanced Landing Page

> A responsive, animated business landing page built during my OctaNet internship task.

[![Live Demo](https://img.shields.io/badge/Live%20Demo-Open-2ea44f?style=for-the-badge&logo=vercel)](https://octanet-github-io.vercel.app)

**Live demo:** https://octanet-github-io.vercel.app

## Features
- Sticky navigation bar
- Hero section with fade-in animation
- About Us, Services, Features, Pricing (Basic / Standard / Premium) and Testimonials sections
- Contact form
- CSS hover, slide-in and shine animations

## Tech Stack
HTML5, CSS3 (single `index.html`)

## Run Locally
No build step. Clone the repo and open `index.html` in a browser, or serve it:
```bash
npx serve .
```
